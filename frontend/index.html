Simple 3-Step Process

How CounterCheck Works

Explore the prototype's three-step image-analysis flow. Do not use its output to make real-world authenticity decisions.

1

1. Capture & Upload

Select a clear product image and upload it to the prototype for feature inspection.

2

2. Image-feature Analysis

The Spring Boot API forwards the image to a Python Flask service that calculates image statistics and optional generic ImageNet features.

3

3. Review Experimental Output

Review the heuristic label and score. They are experimental image features, not a validated authenticity rating.
